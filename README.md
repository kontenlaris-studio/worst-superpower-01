A make.fun entry for the **Worst Superpower** bounty: invent the most useless
superpower in one line of at most 140 characters.

> I can summon rain, but only indoors, and only above my own head, and only when I'm already holding an umbrella.

Run it:

```bash
python3 main.py
```

It prints the line and writes it to `/output/entry.txt`.
